# Objects — source-backed nouns

Inputs: one task, the [catalog](../CLAUDE.md), and [schema](../_meta/schema.md).
Process: choose one card in the [generated index](_index.md), then open its sources.
Outputs: a reviewed object card; do not duplicate policy fields or complete audits.
Human check: verify the owning file and first-order Hits / Does not hit.
Copy the [object template](../_templates/object.md) for a new noun.

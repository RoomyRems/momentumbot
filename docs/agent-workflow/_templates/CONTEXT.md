# Stable workflow templates

These are reusable forms, not completed work or acceptance evidence. Use the
[work-item templates](work-item/CONTEXT.md) for an actual scoped run. Keep stable
prompts here; put the resulting decisions and observations under the concrete
run path described by [the workflow router](../CONTEXT.md).

Do not duplicate shared policy into templates. Reference
[AGENTS.md](../../../AGENTS.md), the current status and the relevant component.
Do not create empty run directories simply because a template exists.

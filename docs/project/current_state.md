## Active gate

Freeze Micro-v0.1 activity for every held-out candidate before opening Ross behavior labels. The replay must:

1. start no earlier than the candidate's completed-minute qualification;
2. act only on fully completed ten-second bars before 10:00 ET;
3. bind same-day support to the frozen scanner bar grid;
4. distinguish provider-unavailable candidates from genuine zero-plan candidates;
5. preserve trades, derived bars, support inputs and per-candidate runtime artifacts;
6. remain descriptive and ineligible for policy promotion.

This layer measures technical opportunity generation. It is not yet a portfolio backtest: repeated plans can belong to one campaign, and buying power, divided attention, discretionary selection, Level 2, tape-based management and complete exits are not modeled here.

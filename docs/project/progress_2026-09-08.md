# MomentumBot progress — September 8, 2026

MomentumBot has run its first original historical account panel. The source
foundation and account orchestration now work together, and the first result
exposes specific blockers in exit-reference handling and exact risk accounting.
The account backtest remains incomplete. Profitability, reliable paper operation
and full Ross Cameron strategy coverage have not been established.

## What this step completed

The isolated historical replay is implemented and its first result is frozen.
All 12 alternative account paths recorded an entry on the first date and then
stopped at an exit signal without a fresh decision-time quote. The remaining
348 session slots preserve blocked prior state. All original opportunities and
unavailable references remain in the result; open shares and unsubmitted exits
were retained. No path is a completed account backtest.

The source pair is complete. The relevant prior quote was 195.7 ms old, exceeding
the frozen 100 ms freshness rule. A quote arriving later cannot be used at that
earlier signal time. Separately, the independent accounting checker found a
binary floating-point discrepancy in six stress paths: open risk was recorded
as `0.39999999999999947` instead of exact `$0.40`. Both findings are preserved;
no thresholds, sources, account balances or results were retuned.

All 2,200 local tests passed with no skips; 94 focused tests passed normally and
optimized. GitHub reproduced the exact runtime and the same independent-check
failure. General CI passed, but the dedicated historical workflow is correctly
recorded as failed. This is a reproducible first experiment and a concrete
diagnosis, not successful account verification. The
[component record](../research/sealed_historical_account_replay_v01.md) and
[failure audit](../../research/data-audits/sealed-historical-account-replay-v0.1-first-runtime-failure.json)
contain the full evidence.

## Remaining path to the first meaningful account result

1. Repair exact open-risk projection in an isolated child, with regression cases
   using nonbinary-cent prices and unchanged account risk limits.
2. Register causal handling of an unsubmitted exit awaiting a fresh quote within
   original source windows and existing order-attempt ceilings. Preserve the
   failed first run and all known state; do not relax freshness or use future
   quotes to backdate an order.
3. Run the registered child against the unchanged 12-path, 30-session panel and
   freeze all results, including any remaining blocked or incomplete paths.
   Missing carry evidence still requires explicit source resolution.
4. Evaluate eligible frozen results, then open retrospective Ross evidence for the
   registered comparison. Further held-out and prospective paper evidence is
   needed before promoting any policy.

The practical milestone is an end-to-end, causally valid account result that
we can inspect and reproduce. Engineering completion and evidence of a trading
edge are different measures; assigning one percentage to both would be misleading.
